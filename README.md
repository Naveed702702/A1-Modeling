# My Musical Instrument

## About
This is a simple musical instrument made with JavaScript and Tone.js.

## How to Play
1. Open the website.
2. Click **Start Instrument**.
3. Press A, S, D, F, G, H, or J to play notes.
4. Release the key to stop the note.
5. Press 1 or 2 to change the sound.

## Keyboard Controls
- A: C4
- S: D4
- D: E4
- F: F4
- G: G4
- H: A4
- J: B4
- 1: Sine sound
- 2: Square sound

## Technologies Used
- HTML
- JavaScript
- Tone.js
